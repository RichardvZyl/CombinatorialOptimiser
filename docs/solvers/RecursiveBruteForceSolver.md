# RecursiveBruteForceSolver

Description
- Recursive implementation of exhaustive permutation enumeration. Functionally equivalent to brute force but demonstrates recursive traversal and stack behaviour.

Complexity
- Time: O(n!)
- Space: O(n) (plus recursion stack)

Typical practical limits
- Workable n: ≤ 10; recursion depth may be a practical constraint in some environments.

Parameters / options
- None.

Top use cases
1. Correctness checks and small example problems.
2. Teaching recursion and search tree traversal.
3. Comparative performance tests versus iterative Heap's algorithm.

CLI example
- dotnet run -- --solver RecursiveBruteForce
